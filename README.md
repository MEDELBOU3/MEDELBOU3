## About Me

I am a **Computer Science & Artificial Intelligence student** interested in building software that combines **programming, AI, real-time graphics, interactive systems, and product design**.

I enjoy creating projects from the ground up and learning how complex systems work internally. My work ranges from web applications and algorithms to 3D tools, game-engine systems, animation workflows, rendering experiments, and AI-related research.

My current focus is on building **SM Engine**, a modular real-time 3D creation and game-development environment based on **Three.js, JavaScript, Electron, WebGL, and WebAssembly-oriented tooling**.

```text
Current interests
├── Artificial Intelligence & Machine Learning
├── Game Engine Architecture
├── Real-Time 3D Graphics
├── Rendering & Optimization
├── Animation Systems
├── Full-Stack Development
├── Algorithms & Research
└── UI / UX for complex creative tools
```

## What I Am Building

### SM Engine

<div align="center">
  <a href="https://github.com/MEDELBOU3/SM-Engine">
    <img src="https://github.com/MEDELBOU3/SM-Engine/raw/main/screenshoots/Screenshot%20(742).png" width="88%" alt="SM Engine"/>
  </a>
</div>

**SM Engine** is my largest ongoing engineering project: a modular editor and runtime for real-time 3D creation, modeling, animation, gameplay systems, rendering, terrain, virtual production, scripting, build/export workflows, and extensibility.

Some areas I am actively exploring inside the project include:

- Editor and workspace architecture
- 3D modeling and sculpting tools
- Timeline, graph and animation systems
- Player / character architecture
- Physics and gameplay runtime
- AI and behavior systems
- Rendering and lighting
- Terrain and water
- 2D animation
- Plugin architecture
- Build and standalone export systems
- Performance optimization for larger scenes
